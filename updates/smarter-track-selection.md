# Smarter track selection

> Draft landing page — the associated work is awaiting review and release.

This page will explain how a shortlist helps the DJ find a better next record:
the station establishes an eligible musical field, then the DJ makes the final
editorial choice.

It will introduce the default Context → Continuity → Exploration shape,
controllable shortlist breadth, and Musical Leanings as a private soft
tie-breaker.
