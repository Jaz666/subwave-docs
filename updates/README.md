# Updates

Each file here is a standalone, shareable landing page for one meaningful
SUB/WAVE improvement. It should make sense to someone arriving from a social
post with no knowledge of the associated pull request.

Use a short stable filename and this broad shape:

1. A plain-English opening: what changed and why it matters.
2. What listeners will notice.
3. What operators can control.
4. What remains protected or unchanged.
5. A small FAQ and links to related Field Guide pages.

Keep branch names, internal diagnostics, benchmark mechanics, and implementation
history out of these pages. Link to the official manual where configuration
instructions belong, and state clearly when an update is still awaiting release.
