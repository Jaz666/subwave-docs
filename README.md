# SUB/WAVE field notes

Practical, user-facing notes to accompany Jaz666's SUB/WAVE contributions.
They explain what new features mean in a real station, how to make good use of
them, and the lessons learned while running one.

This is a companion to the [official SUB/WAVE documentation](https://github.com/perminder-klair/subwave/tree/develop/docs), not a replacement for it.
Features described here may still be awaiting review or release; every update
page will say so clearly.
