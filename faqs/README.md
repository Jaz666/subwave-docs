# Frequently asked questions

This directory will hold concise, reusable answers for questions that recur
across update pages and social conversations.

Start with the question a new operator would actually ask. Link back to an
update or Field Guide page for the fuller explanation, and to the official
documentation for exact setup steps.

Initial topics:

- How does a DJ link stay factual without sounding robotic?
- What are Sleeve Notes, and do I need to write them myself?
- What is a track shortlist, and does it take choice away from the DJ?
- Should a show use soft or strict music filters?
- How much should I put in a show brief or persona prompt?
